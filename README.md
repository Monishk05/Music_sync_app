# SyncTune 🎵

SyncTune is a real-time music synchronization web application that allows users to listen to music together and communicate through real-time chat.

## Features

- Create and join rooms using a unique room ID
- Real-time synchronized music playback
- Play, pause and seek synchronization
- Multiple-song playlist
- Automatic next-song playback
- Real-time chat
- User names and member count
- Reconnection handling
- Playback drift correction

How to Run
Frontend
    cd client
    npm install
    npm run dev
Backend
    cd server
    npm install
    node server.js

The frontend runs on:
http://localhost:5173

The backend runs on:
http://localhost:5000
